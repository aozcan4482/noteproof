# Kabul senaryosu S7 — Hesapsız, sunucusuz proof kontrolü

Görev: AYS-1 · Sahip: aysu · İnceleyen: emine · Kural seti sürüm 2.3

## 1. Story

| | |
| --- | --- |
| Epic | E3 — Search, copy warnings and proof pages |
| Rol | Note verifier (doğrulayıcı) |
| İstek | Hesap açmadan bir bağlantıdan proof kontrol etmek |
| Gerekçe | Notun kimde önce olduğunu arşive güvenmeden çözebilmek |

Proposal'daki metin: *As a note verifier, I want to check a note's proof from a link without an account,
so I can settle who had a note first without trusting the archive.*

## 2. Kabul kriteri

Metin proposal'dan aynen alınmıştır, değiştirilmez.

- **Given** a note file and its proof link
- **When** I open the proof page while the archive's server is offline
- **Then** the page recomputes the hash, walks the Merkle path and shows the block time of the signet
  transaction

## 3. Proposal senaryosu: reddetme (Scen_Rejection)

- **Given** a note file that was changed by one character after it was timestamped,
- **when** its proof is checked,
- **then** the hash does not match and the page says it is not the registered file.

Aşağıda C bölümü olarak çalıştırılır.

## 4. Gereken test verisi

| Veri | Açıklama |
| --- | --- |
| Not dosyası | **Kanıtlandı** durumunda bir not (ör. S1'de kaydedilen `s1-not.pdf` ya da bir metin notu) |
| Proof dosyası | Aynı notun proof JSON dosyası (`02` bölüm 6 biçimi). Sunucu açıkken notun proof'undan indirilip saklanır |
| Değiştirilmiş kopya | Not dosyasının tek karakteri değiştirilmiş kopyası. Metin notunda bir harf değiştirmek en kolayı |
| Ortam | `v0.9.0` ya da sonrası, signet. Proof sayfası arşivin sunucusundan bağımsız açılmalı (ör. `web/` klasörü ayrı bir statik sunucudan) |

Hesap gerekmez. Test, giriş yapılmamış bir tarayıcıda (ör. gizli pencere) yapılır.

## 6. Geçti / kaldı ölçütü

- B: sunucu kapalıyken sayfa hash'i yeniden hesaplıyor, Merkle yolunu yürüyor ve signet işleminin blok
  zamanını gösteriyor.
- C: tek karakteri değişen dosyada hash eşleşmiyor ve sayfa dosyanın kayıtlı dosya olmadığını söylüyor.
- İki bölüm de geçmeli.

## 7. Açık noktalar

- Blok zamanı proof dosyasında da yazıyor (`blockTime`). Kriter "signet işleminin blok zamanını gösterir"
  diyor; zamanın zincirden doğrulanması (public signet API'si, K-008) gelmezse sayfa "Zincir kontrol
  edilemedi" der. Bu durumda B'nin sonucu "kaldı" mı yoksa "kısmen" mi sayılacak, Arda'ya sorulacak.
- Proof sayfasının sunucudan bağımsız nereden açılacağı (aynı makinede ayrı statik sunucu mu, başka bir
  adres mi) Erdener ile netleştirilecek.
